# Python Beginner Projects

Welcome to my Python Beginner Projects repository!

This repository contains the projects I built while learning Python. Each project helped me practice different programming concepts such as loops, functions, conditionals, lists, dictionaries, and problem-solving.

## Projects

### 1. Calculator

A simple calculator that performs:

* Addition
* Subtraction
* Multiplication
* Division

### 2. Number Guessing Game

A game where the computer generates a random number and the player tries to guess it.

### 3. Rock Paper Scissors

A classic Rock, Paper, Scissors game where you play against the computer.

### 4. To-Do List

A command-line To-Do List application that allows you to:

* Add tasks
* View tasks
* Remove tasks
* Mark tasks as completed

## Technologies Used
